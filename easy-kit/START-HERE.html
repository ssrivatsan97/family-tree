🌳 Your family tree: start here

This folder is a complete family tree website. You don't need to install anything or know any computer code.

1. Look at it

1 Make sure you have unzipped (extracted) the folder. On Windows: right-click the zip, then Extract All.
2 Double-click index.html. Your web browser opens a sample family tree.
If it opens in another program, right-click it, choose Open with, then pick Chrome, Edge, Safari or Firefox.

2. Put in your own family

3 Tap any person, then use the buttons under Make changes:
  • ✏️ Edit all details: change the name, nickname, gender or photo.
  • ➕ Add child and ➕ Add husband/wife: add new people.
  • 🗑 Remove from tree: delete sample people you don't need.
Easiest way to start: change the sample people into your own relatives with Edit all details, then add or remove people as needed.
4 When you're done, press 💾 Save family file at the top.
  • Chrome or Edge: a save window opens. Choose this folder and replace family-data.js.
  • Safari or Firefox: the file goes to your Downloads. Move it into this folder and replace the old family-data.js.
Until you save, your changes are only kept in this browser on this computer.

3. Put it on the internet (free)

5 Go to app.netlify.com/drop and drag this whole folder onto the page. In a few seconds you get a link.
6 Create a free Netlify account when it asks, so your site stays online. Then in Netlify go to Site configuration → Change site name and pick something hard to guess, like our-family-k7q2m.
7 Send the link to your family. They can look, search and tap on people. Nobody can change the tree online. Only you can, from your computer.

4. Update it later

Double-click index.html in this folder on your computer → make changes → Save family file → in Netlify open your site → Deploys → drag this folder onto the upload area.

Keep it safe

  • Anyone with the link can see the tree. There is no password in this Easy kit. Search engines are told not to list it, but please don't post the link publicly. If you want a family password, use the online version instead (see the project's GitHub page).
  • Keep a copy of this folder somewhere safe (for example on a USB stick). It is your family tree.
  • Photos you add are stored inside family-data.js, so keep that file safe too.

Getting a newer version of this kit

When someone sends you a newer kit: unzip it, then copy your family-data.js (and anything in your photos folder) into the new folder, replacing the sample. Your family stays the same, with the new features.
